链表翻转与 K 个一组速查卡 (Cheat Sheet)

为高频链表指针操作提炼的极简心智备忘与零 Bug 代码模板。

一、四种经典链表翻转模式对比

模式分类 时间复杂度 空间复杂度 核心终止条件 (递归基/循环基) 关键指针暂存
1. 单链表整体翻转 (LC 206) $O(N)$ $O(1)$ curr == nil next = curr.Next
2. 开闭区间翻转 [a, b) $O(K)$ $O(1)$ curr == b 区间右边界 b
3. K 个一组递归分治 (LC 25) $O(N)$ $O(N/k)$ 栈空间 剩余节点不足 k 个 (原样返回) 第 $k+1$ 个节点 nextGroupHead
4. K 个一组迭代哨兵 $O(N)$ $O(1)$ 严格原地 探查到底部不足 k 个退出 prevGroupTail 与 nextGroupHead

二、K 个一组翻转的「五步心智模型」

口诀：先探 $k$ 步防尾溢，不够直接退原局；够数记下第 $k+1$，调头反转本组序；子链递归得新头，尾部缝合全归一。
  1. Step 1 探测数量：前探指针从 head 向前走 $k$ 步。若中途为 nil，说明尾部节点不足 $k$ 个，直接返回 head（保持原序）。
  2. Step 2 锁定后继：探查完毕后，当前指针所处位置恰好为第 $k+1$ 个节点（nextGroupHead）。
  3. Step 3 区间翻转：将 [head, nextGroupHead) 闭开区间内的 $k$ 个节点进行局部反转，得到新头节点 newHead。此时原 head 变为当前组尾节点。
  4. Step 4 递归子链：调用 reverseKGroup(nextGroupHead, k) 递归处理后续所有节点，得到后继链表新头 remainedHead。
  5. Step 5 缝合归一：将当前组尾部 head.Next 赋值为 remainedHead，并向外层返回 newHead。

三、标准 Go 语言区间反转原子模板

// reverseRange: 反转左闭右开区间 [head, stop) 内的所有节点
// 来源: head 为待反转起始节点，stop 为终止边界（不参与本次反转）
// 用于: 返回反转后的局部新头节点
func reverseRange(head, stop *ListNode) *ListNode {
    var prev *ListNode = nil
    curr := head
    for curr != stop {
        next := curr.Next
        curr.Next = prev
        prev = curr
        curr = next
    }
    return prev // 反转后的新头节点（即原第 k 个节点）
}

四、边界条件防御检查表

  • ☑ $k = 1$ 的退化情况：无需任何实际交换，探 1 步翻转 1 步后维持原状，或在入口处直接 if k <= 1 { return head } 提前剪枝。
  • ☑ 尾部剩余节点不足 $k$：严格保持原有顺序，绝对不能触发整体翻转（如 [1,2,3,4,5], k=3 结果为 [3,2,1,4,5]，末尾 4->5 保持原样）。
  • ☑ 空链表或单节点：head == nil 时在探查第 1 步即返回 nil，安全退出。
  • ☑ 环路防范：确保反转后原 head.Next 必须被重新赋值（接上递归返回结果），否则原 head 会残留指向旧节点的指针形成死循环。
