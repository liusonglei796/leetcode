# 560. 和为 K 的子数组

**难度**: Medium  
**标签**: 哈希表、前缀和、数组

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

## 解题思路

使用前缀和 + 哈希表：
1. 计算前缀和 `sum`
2. 用哈希表存储 `前缀和→出现次数`
3. 查找 `sum - k` 是否在哈希表中

**核心思想**: `sum[i] - sum[j] = k` 等价于 `sum[j] = sum[i] - k`，用哈希表快速查找。

## 代码实现

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> map;
        map[0] = 1;
        int sum = 0, count = 0;
        for (int num : nums) {
            sum += num;
            if (map.find(sum - k) != map.end()) {
                count += map[sum - k];
            }
            map[sum]++;
        }
        return count;
    }
};
```

## 复杂度分析

- 时间复杂度: O(n)
- 空间复杂度: O(n)
