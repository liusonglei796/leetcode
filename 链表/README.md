# 链表专题

LeetCode Hot 100 中与链表相关的题目，共 14 题，按解法分类。

## 快慢指针（3 题）

> 全仓库统一的 2:1 写法：`slow, fast := head, head` +
> `for fast.Next != nil && fast.Next.Next != nil`。
> 条件只判 fast 后面两个节点，所以进循环时 fast 必非 nil，
> `fast = fast.Next.Next` 也不会把它甩成 nil；
> 副作用是 slow 一定停在第 ⌈n/2⌉ 个节点（前半段最后一个），
> 偶数长度时两半等大，奇数时左半段多一个。

| 题号 | 题目 | 难度 | 核心思路 |
|------|------|------|----------|
| 141 | 环形链表 | Easy | 速度差进环后必然相遇；条件只在无环时退出 |
| 142 | 环形链表 II | Medium | 快慢相遇后，一指针从 head 同速再走即入环点 |
| 234 | 回文链表 | Easy | 快慢找中点 → 反转后半段 → 比较 → 还原 |

## 两种 2:1 循环条件的取舍

| 写法 | fast 起点 | 循环条件 | 退出时 slow 在 | 适用 |
|---|---|---|---|---|
| B（本仓库统一采用） | `head` | `fast.Next != nil && fast.Next.Next != nil` | 第 ⌈n/2⌉ 个（前半段最后一个） | 141、142、148、234 |
| A | `head.Next` | `fast != nil && fast.Next != nil` | 第 ⌈n/2⌉ 个 | 同样可用（148 最初的写法） |
| A + `fast = head` | — | — | 偶数时第 n/2+1 个 ❌ | 141/142 侥幸对，234 必错 |

- B 不能让 fast 提前起步（`fast = head.Next`）：n=3 时 slow 会停在节点 1，
  234 的后半段变成 `[2,3]`，比较结果就错了。
- 19、160 不能用这两种写法：19 要求 fast 精确停在尾部起第 n 个（步长必须 1），
  160 靠「两个指针走过等长的路」判定相交，与速度差无关。
